# 와우고 교원 포털

와우고등학교 **교원 전용** — 선생님들이 만들어 쓰는 교내 도구를 한자리에 모은 단일 HTML 포털입니다.
업무 영역(학급 운영 · 수업·평가 · 진학·진로 · 학교 시설·행사)으로 나눠 놓아, 찾던 도구를 바로 열고
주소를 복사해 동료 선생님께 보낼 수 있습니다.

## 🔒 들어가는 법

교내 도구 주소가 들어 있어 **내용 전체를 암호로 잠가** 두었습니다.
주소를 열고 암호를 넣으면 카드가 보입니다. 한 번 넣으면 그 브라우저를 닫을 때까지 다시 묻지 않습니다.

- 암호를 모르시면 **정보 교과 선생님**께 문의하세요.
- 이 저장소에는 암호도, 카드 내용(도구 주소·사용법 글)도 **평문으로 들어 있지 않습니다.**
  `locked.js` 는 PBKDF2-SHA256(20만 번)으로 만든 열쇠로 AES-256-GCM 으로 잠근 덩어리입니다.
- ⚠ 파일을 내려받아 **더블클릭으로 열면 암호가 풀리지 않습니다.** 브라우저가 `file://` 에서는
  암호 풀기(WebCrypto)를 막기 때문입니다. 반드시 **포털 주소(https)** 로 여세요.

## 카드 한 장에 있는 것

| | |
|---|---|
| **바로 열기** | 그 도구를 새 탭에서 엽니다 |
| **🔗** | 공유 링크 복사 — 동료 선생님께 보낼 주소를 복사합니다 |
| **💡 제안하기** | 틀린 곳 · 고장 · 바라는 기능을 메일 쓰기 틀에 채워 보냅니다 |
| **📖 사용법** | 「이럴 때 씁니다 · 쓰는 순서 · 알아 두실 것」을 포털 안에서 읽습니다 |
| 🙋 만든이 · 📅 만든 날 · 🔄 최신 업데이트 | 카드마다 함께 보입니다 |

사용법 쪽은 **주소로 바로 열 수 있습니다** — 포털 주소 끝에 `#how-<도구 열쇠>` 를 붙이면 됩니다.
그 쪽의 [🔗 이 안내 링크 복사] 로 주소를 복사해 메신저에 붙여 보내세요.

## 🧑‍🏫 도구 등록하기

엑셀 양식 하나, 구글 시트 하나라도 올려 드립니다. 포털 아래쪽 **[✉️ 도구 등록 메일 쓰기]** 를 누르고
다섯 가지만 채워 보내 주세요 — ① 이름 ② 만든이 ③ 주소(또는 파일이 있는 곳) ④ 한 줄 설명 ⑤ 어느 칸.
주소가 아직 없으면 「준비 중」 카드로 먼저 올려 두고 나중에 주소만 채울 수 있습니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 포털 전부(CSS·JS 인라인) — 암호 가림막 · 카드 목록 · 사용법 화면 · 제안하기 창 |
| `locked.js` | 암호로 잠근 내용(카드 목록 · 사용법 글). 손으로 고치지 않습니다 |
| `updated.js` | 카드의 「만든 날 · 최신 업데이트」 — 각 도구 깃허브 저장소의 첫·마지막 커밋 날짜 |
| `favicon.svg` | 사이트 아이콘 |

개인정보를 한 글자도 받지 않습니다 — 서버가 없고, 넣은 암호는 그 브라우저를 닫을 때까지만
기억합니다(`sessionStorage`). 학생·학부모 정보는 이 포털에 담지 않습니다.
